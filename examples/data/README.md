# Beispieldaten

Die Dateien stammen aus dem bisherigen Mower-II-Arbeitsablauf und dienen als
realistische Referenz für Import, Simulation, Export und Regressionstests.

- `20261022_AbsteckPunkteLabor_angepasst.txt`: Punktimport im aktuellen Format
- `tracker_station.txt`: Lasertrackerstandpunkt X/Y/Z in Millimeter
- `20261028_Test_abgestecktemarkiertePunkte.mower_export.txt`: Export aus V1

Die Beispieldaten dürfen nicht als Kalibrierung oder Freigabe für einen realen
Hardwareeinsatz verwendet werden.
